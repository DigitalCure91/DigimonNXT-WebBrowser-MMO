DIGIMON NXT v0.7.2 — COMPLETE WORLD SERVER COMMAND REFERENCE
Blank-password release • Schema 8 • Windows physical-local administrator console

OPEN THE CONSOLE
Run tools\start_world_server_windows.bat on the physical server PC and accept
administrator elevation. Start Apache and MySQL first. The default installed
game folder is C:\xampp\htdocs\DigimonNXT. Run Create / Repair Schema after
updating the game; keep your installed config\app.php and saved database.

COMMAND NOTATION
<value> is required. [value] is optional. Do not type the angle/square brackets.
Quote an argument containing spaces, for example "A short support message".
Account selectors accept exact usernames or #account-id, such as #1001.
Species/item selectors accept catalog IDs, exact slugs or exact quoted names.
Owned Digimon use instance IDs from digimon list, not species catalog IDs.
Commands accept an optional leading period: .givemoney works like givemoney.
Command names are case-insensitive; supply option keywords exactly as shown.
Pagination is 30 records per page unless stated otherwise. Pages start at 1.
Input is limited to 2,048 bytes per command; control characters are rejected.
Numeric limits use whole integers, without commas, decimals or a leading minus.
Text/password lengths stated in bytes are UTF-8 lengths; non-ASCII characters
may occupy more than one byte.

EXAMPLES ARE ILLUSTRATIVE
Replace DemoTamer, #1001 and instance 1234 with real accounts/IDs from your world.
The command guide does not create the example accounts or run these commands.

PASSWORDS AND CONFIRMATION
account create and account password open a masked password prompt (8–72 bytes).
Do not add a password to the command line. Password values are excluded from
command history, activity records and administrator audit records.
Commands marked CONFIRM ask you to type CONFIRM before applying the operation.
Every other response cancels the operation. Review the target and values first.
Escape cancels the current input or prompt without applying that operation.

The exact local controls, stream filters and keyboard shortcuts are listed
at the end of this reference. docs/WORLD_SERVER_CONSOLE.md covers installation,
traffic scope, log retention, session revocation and troubleshooting.

ACTIVE BATTLES AND SAFE EDITS
Granting/removing/changing Digimon, healing, party edits, item edits and scan
edits refuse a supported active saved wild battle. Have the player finish the
battle before retrying. Kicking or resetting a password revokes sessions but
does not silently award, erase or complete that saved battle.

An account ban, password change, role change or kick invalidates prior sessions.
The player is refused on their next server request; a page already loaded in a
browser cannot disappear instantly. Account unlock is separate from unban.

PHYSICAL-LOCAL ACCESS
The interactive host requires an elevated administrator in the active physical
Windows console session. It is unavailable through a browser, network listener,
Remote Desktop, SSH or redirected input. Keep tools outside the web root.
Game admin/moderator roles do not grant operating-system console access.
There are no raw SQL, shell execution or database-drop commands.

Closing this window does not stop Apache, MySQL, your other MMOs or the separate
persistent tamer worker. Keep the worker installed for zero-player bot activity.

LOCAL CONSOLE COMMANDS — DISPLAY AND WINDOW CONTROLS
These do not change player data. They are handled by the Windows host.

console help
  Show the local display commands and keyboard shortcuts.

console status
  Show the installed game path, PHP executable, journal path, Apache access-log
  path, URL prefix, traffic mode, category filter, pause state and Apache switch.
  Use status (without console) for database/world state.

console traffic summary|full|off
  summary: default; show useful activity and group repeats, polling and assets.
  full: show more individual requests, capped at 8 traffic lines per second;
        overflow is summarized. It never becomes an unlimited scrolling flood.
  off: hide request traffic while keeping other selected activity visible.
  Example: console traffic full

console filter all|request|auth|game|bots|admin|system
  Select one feed category or all. Default all. Administrator command results
  remain visible regardless of this filter or a paused feed.
  Example: console filter bots
  Example: console filter all

console apache on|off
  Enable or disable reading this game's static/missing-route traffic from the
  configured Apache access log. Successful PHP routes are skipped; failed PHP
  requests can appear in both Apache and structured records. Optional; the structured game
journal works without it.
  Example: console apache off

console pause
  Pause the activity display. Administration results remain visible. The game,
  background worker and journal continue. This is not a maintenance switch.

console resume
  Resume new activity display. Hidden events remain in the journal; pausing does
  not create an unlimited in-memory replay queue.

console clear
  Clear the current terminal display. Does not erase logs, audit or player data.
  Shortcut: Ctrl+L.

exit
quit
  Close this console window. The web game, Apache, MySQL, other MMOs and the
  separate background tamer task keep running.

KEYBOARD
Enter: submit the current command or answer the current prompt.
Left/Right, Home/End, Backspace/Delete: edit the current input.
Up/Down: browse up to 100 commands in memory; account create/password operations
         are excluded. History is not saved to a disk history file.
Tab: complete a supported command.
Esc or Ctrl+C: clear input or cancel a pending password/confirmation prompt.
Ctrl+L: clear the display.
New feed lines preserve your partly typed command and current cursor position.

FEED COVERAGE AND RETENTION
Times are UTC. Dynamic PHP routes that load the game bootstrap produce method,
script path, status and duration records with known account identity. Committed
player/bot actions use auth/game/bots events. Background actions show a local
source; guests and unknown identities are labelled explicitly.

The optional Apache reader adds this game's static/missing-route traffic,
filtered by NXT_URL_PATH. Static assets are marked unattributed: the console does
not infer an account from the IP. When NXT_URL_PATH is /, use a dedicated game
virtual-host access log so another MMO's requests are not included.

Repeated requests, assets, bots and polling are summarized every 15 seconds.
For each bot action type, the first event in a 15-second window can show its real
tamer/IP, subject to the overall display limit. Remaining events use neutral
AI tamers (grouped) labels; grouped counts exclude the displayed sample. Repeated
authentication/game summaries also use neutral event labels. Administrator
results remain visible. Startup attaches to new records without replaying the log.
Use logs for recent retained entries. A skipped backlog or write failure produces
an explicit warning rather than being reported as complete capture.

Structured journal location: <installed game>/storage/world-console/events.php
Rotation: 10 MiB per file, five rotated files plus the active file (~60 MiB).
The console does not manage Apache's own access-log rotation or retention.
No query values, request bodies, cookies, password values or credential headers
are shown. Keep local journal/audit access restricted to server administrators.
