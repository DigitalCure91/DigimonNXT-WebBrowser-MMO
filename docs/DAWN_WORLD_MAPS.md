# Dawn World map reference — v0.7.0

All 264 supplied map IDs are available in the atlas. The table lists the natural uploaded image dimensions, accessible floor sections and standard encounter level range. Rare Paradox signals use their separate existing profile.

Environment labels describe the artwork and organize the NXT atlas; they are not claimed to be canonical Dawn location names. Every floor section has a safe landing. Region chains and entry gates provide NXT travel rather than original story warps.

Search the atlas by any area number below. Use **Area landings** inside maps with more than one section. [Exploration guide](DAWN_WORLD.md)
